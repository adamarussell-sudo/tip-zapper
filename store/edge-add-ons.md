# Microsoft Edge Add-ons listing

Optional. Edge users can already install from the Chrome Web Store, but a native listing is free and skips the "allow extensions from other stores" prompt.

1. Register in [Partner Center](https://partner.microsoft.com/dashboard/microsoftedge/overview). There's no registration fee.
2. Click **Create new extension** and upload `dist/tip-zapper-<version>-chrome.zip`. Edge uses the same build as Chrome.
3. Reuse the text and images from [`chrome-web-store.md`](chrome-web-store.md): description, category (Shopping), screenshots, small promo tile, privacy policy URL and support URL.
4. Answer the questions the same way as for Chrome: no personal data collected, no remote code.
